# WRITEBACK_CONTRACT (Phases F-J)

All paths compose canonical contracts; none create authority.

1. Research (F): ingest_documents -> UNSUPPORTED claims; support ONLY via
   immutable knowledge.evidence_linked; supersession preserves history;
   expired fresh_until -> STALE research-queue cue; poison refused at entry.
2. Engineering outcome (G): requires verifier PASS; writes STARTED+terminal
   verdict pair, V3 outcome (predicted/actual, UNKNOWN when missing),
   decision+outcome claims, recallable accepted Tier C lessons.
3. New-project lifecycle (H): rejected ideas keep durable rationale
   (candidate evidence_json + optional recallable REJECTED IDEA lesson);
   architecture decisions are supersedeable claim chains; entity links to
   resource_id.
4. Failed attempts (I): verifier FAIL verdict + FAILURE ATTEMPT lesson
   (labeled "NOT accepted truth", recallable). No decision/outcome claims.
5. Procedure experience (J): procedure.updated flips lifecycle;
   procedure.created upsert carries bounded confidence movement
   (+0.10 PASS capped 0.95, -0.15 FAIL floored 0.05, -0.20 + STALE on
   reality change). PROVEN_ONCE never auto-TRUSTED.

Defense gate (_scan) wraps every free-text entry: directive imposter,
verdict imposter, secret-like, trust self-promotion patterns are refused
(WritebackRejected) before any ledger/Tier-C/Obsidian write.
